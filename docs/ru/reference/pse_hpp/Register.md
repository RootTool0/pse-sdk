## pse::Register::

Пространство имен `pse::Registers::` содержит набор **шаблонных утилит** _(хелперов)_, предназначенных для быстрой и безопасной работы с битовыми полями и данными внутри **регистров** `PseRegister`

#### Bit

| Сигнатура                                                                                             | Тип возвращаемого значения | Описание                                                                                                                                                                                                                                                                         |
|-------------------------------------------------------------------------------------------------------|----------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `setBit(PseRegister& outRegister, const uint8_t inOffset, const bool inValue)`                        | `void`                     | Изменяет регистр `outRegister`, записывает в него один бит с значением `inValue` по указанному смещению `inOffset`                                                                                                                                                               |
| `getBit(const PseRegister inRegister, const uint8_t inOffset)`                                        | `bool`                     | Считывает регистр `inRegister`, возвращает значение одного бита по указанному смещению `inOffset`                                                                                                                                                                                |
| `updateBit(const bool& toRegister, PseRegister& outRegister, const uint8_t inOffset, bool& outValue)` | `void`                     | Если флаг `toRegister` равен `true`, то записывает значение `outValue` в бит по смещению `inOffset` регистра `outRegister`, иначе считывает этот бит и сохраняет его в `outValue`<br><br>_(по сути флаг `toRegister` определяет какую команду выполнить: `setBit` или `getBit`)_ |

#### Int

| Сигнатура                                                                                                                           | Тип возвращаемого значения | Описание                                                                                                                                                                                                                                                                                      |
|-------------------------------------------------------------------------------------------------------------------------------------|----------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `getInt(const PseRegister inRegister, const uint8_t inOffset)`                                                                      | `T`                        | Считывает регистр `inRegister`, возвращает целочисленное значение типа `T` по указанному смещению `inOffset`<br><br>_(размер типа `T` не должен превышать **32 бит**)_                                                                                                                        |
| `template<typename T> setInt(PseRegister& outRegister, const uint8_t inOffset, const T inValue)`                                    | `void`                     | Изменяет регистр `outRegister`, записывает в него целочисленное значение inValue типа `T` по указанному смещению `inOffset`<br><br>_(размер типа `T` не должен превышать **32 бит**)_                                                                                                         |
| `template<typename T, typename Q> updateInt(const bool& toRegister, PseRegister& outRegister, const uint8_t inOffset, Q& outValue)` | `void`                     | Если флаг `toRegister` равен `true`, то записывает значение `outValue` _(приведенное к типу `T`)_ по смещению inOffset регистра `outRegister`, иначе считывает это значение и сохраняет его в `outValue` _(приведенное к типу `Q`)_<br><br>_(размер типа `T` не должен превышать **32 бит**)_ |

#### BitAs

| Сигнатура                                                                                                                                                | Тип возвращаемого значения | Описание                                                                                                                                                                                                                                                                    |
|----------------------------------------------------------------------------------------------------------------------------------------------------------|----------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `template<typename T, uint8_t bitCount> getBitsAs(const PseRegister inRegister, const uint8_t inOffset)`                                                 | `T`                        | Считывает регистр `inRegister`, возвращает значение заданной длины `bitCount`, приведенное к типу `T`, по указанному смещению `inOffset`                                                                                                                                    |
| `template<typename T, uint8_t bitCount> setBitsAs(PseRegister& outRegister, const uint8_t inOffset, const T inValue)`                                    | `void`                     | Изменяет регистр `outRegister`, записывает в него значение `inValue` заданной длины bitCount по указанному смещению `inOffset`<br><br>_(параметр `bitCount` должен быть в диапазоне **от 1 до 32 включительно**)_                                                           |
| `template<typename T, uint8_t bitCount, typename Q> updateBitsAs(const bool& toRegister, PseRegister& outRegister, const uint8_t inOffset, Q& outValue)` | `void`                     | Если флаг `toRegister` равен `true`, то записывает значение `outValue` _(длиной `bitCount`)_ по смещению `inOffset` регистра `outRegister`, иначе считывает его и сохраняет в `outValue`<br><br>_(параметр `bitCount` должен быть в диапазоне **от 1 до 32 включительно**)_ |
