## pse::Quat::

Пространство имен `pse::Quat::` содержит набор **вспомогательных функций** _(хелперов)_, предназначенных для создания и инициализации кватернионов `PseQuat` на основе **углов Эйлера** по последовательности вращения **ZYX** _(Unreal Engine: Z - вверх, X - вперед)_

| Сигнатура                                                           | Тип возвращаемого значения | Описание                                                                                                               |
|---------------------------------------------------------------------|----------------------------|------------------------------------------------------------------------------------------------------------------------|
| `fromRadians(const float pitch, const float yaw, const float roll)` | `PseQuat`                  | Вычисляет и возвращает кватернион `PseQuat` на основе углов Эйлера _(Тангаж, Рыскание, Крен)_, заданных в **радианах** |
| `fromDegrees(const float pitch, const float yaw, const float roll)` | `PseQuat`                  | Вычисляет и возвращает кватернион `PseQuat` на основе углов Эйлера _(Тангаж, Рыскание, Крен)_, заданных в **градусах** |
