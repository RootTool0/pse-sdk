## pse::Events::

Пространство имен `pse::Events::` содержит набор **шаблонных утилит** _(хелперов)_, предназначенных для быстрой и безопасной работы с **Event-буфером** _(см. **[[Reference > Pse.h]](../pse_h/index.md)** и **[[Reference > Structures.h > PseEventBuffer]](../structures_h/PseEventBuffer.md)**)_

| Сигнатура                | Тип возвращаемого значения | Описание                                                                                                                                                                                                                                                                                                                                                              |
|--------------------------|----------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `poll(PseData& outData)` | `int32_t`                  | Извлекает событие из Event-буфера. Автоматически парсит и вызывает колбэки для известных типов событий _(реализовано для: `PSE_EVENT_ELEMENT_CHANGED`)_. Записывает полученное событие в `outData`<br><br>**Коды возврата:**<br>`1` - Успешно обработано<br>`2` - Неизвестное событие _(не удалось обработать)_`-1` - Буфер событий пуст _(событие не было получено)_ |
| `poll()`                 | `int32_t`                  | Облегченная перегрузка. Вызывает `poll(PseData& outData)` внутри себя со временным пустым буфером. Удобна для циклов, где не требуется ручной перехват неизвестных событий                                                                                                                                                                                            |
