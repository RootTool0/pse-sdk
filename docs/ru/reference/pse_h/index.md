## C-API Справочник функций

Экспортируемый C-интерфейс _(`extern "C"`)_ для интеграции **SDK** с **другими языками программирования** и обеспечения **бинарной совместимости** _(ABI)_

## Buffers / Core

| Сигнатура                        | Тип возвращаемого значения | Описание                                                       |
|----------------------------------|----------------------------|----------------------------------------------------------------|
| **pseInitializeBuffers(void)**   | `int32_t`                  | Инициализирует и аллоцирует **Shared Memory**                  |
| **pseDeinitializeBuffers(void)** | `void`                     | Освобождает дескрипторы и закрывает сегмент разделяемой памяти |

| Сигнатура                            | Тип возвращаемого значения | Описание                                                                |
|--------------------------------------|----------------------------|-------------------------------------------------------------------------|
| **pseGetBuffersAddress(void)**       | `PseBuffers*`              | Возвращает указатель на корень структуры **PseBuffers**                 |
| **pseGetCommandBufferAddress(void)** | `PseCommandBuffer*`        | Возвращает прямой указатель на **командный буфер**                      |
| **pseGetEventBufferAddress(void)**   | `PseEventBuffer*`          | Возвращает прямой указатель на **событийный буфер**                     |
| **pseGetSharedMemoryHandle(void)**   | `void*`                    | Возвращает системный дескриптор (**Handle**) созданного сегмента **ОС** |

## Command Buffer / Methods

### Базовые функции

| Сигнатура                             | Тип возвращаемого значения | Описание                                                                        |
|---------------------------------------|----------------------------|---------------------------------------------------------------------------------|
| **pseCommandBufferSynchronize(void)** | `void`                     | Блокирует поток (**Spin-wait**), пока игра не выполнит все отправленные команды |

### Поштучный режим _(SINGLE - Immediate Access)_

Синхронный **RPC-механизм**: "запрос-ответ" через одну ячейку памяти

| Сигнатура                                                                  | Тип возвращаемого значения | Описание                                                                                                    |
|----------------------------------------------------------------------------|----------------------------|-------------------------------------------------------------------------------------------------------------|
| **pseCommandBufferSinglePush(const PseData\* pInData)**                    | `uint32_t`                 | Запись одной команды. Возвращает абсолютный индекс слота                                                    |
| **pseCommandBufferSingleWait(uint32_t absoluteIndex, PseData\* pOutData)** | `void`                     | Ожидает завершения на индексе и копирует результат в **pOutData**                                     |
| **pseCommandBufferSinglePushAndWait(PseData\* pOutData)**                  | `void`                     | Синхронный вызов: отправляет команду и блокирует поток, а результат записывает обратно в **pOutData** |

### Пакетный режим _(BATCH - Copying)_

Групповой конвейер команд: Результаты возвращаются в тот же самый исходный массив данных

| Сигнатура                                                                                 | Тип возвращаемого значения | Описание                                                                                       |
|-------------------------------------------------------------------------------------------|----------------------------|------------------------------------------------------------------------------------------------|
| **pseCommandBufferBatchPush(const PseData\* pInData, uint32_t count)**                    | `uint32_t`                 | Копирует пакет из **count**-количество команд в кольцо. Возвращает стартовый индекс            |
| **pseCommandBufferBatchWait(uint32_t absoluteIndex, PseData\* pOutData, uint32_t count)** | `void`                     | Блокирует поток до выполнения пакета игрой и заменяет массив **pOutData** результатами   |
| **pseCommandBufferBatchPushAndWait(PseData\* pOutData, uint32_t count)**                  | `void`                     | Синхронно отправляет пакет и ожидает перезаписи **pOutData** выходными результатами игры |

### Режим прямого доступа _(RAW - In-Place / Zero-Copy)_

Максимально производительный режим: **SDK** пишет команду прямо в кэш-линию **Shared Memory**, а затем там же дожидается результата игры

| Сигнатура                                                                         | Тип возвращаемого значения | Описание                                                                                                                    |
|-----------------------------------------------------------------------------------|----------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| **pseCommandBufferRawAt(uint32_t absoluteIndex)**                                 | `PseData*`                 | Возвращает прямой указатель на **PseData** ячейку по абсолютному индексу в кольцевом буфере для **raw чтения/записи** |
| **pseCommandBufferRawReserve(uint32_t count)**                                    | `uint32_t`                 | Резервирует count-количество слотов под Zero-Copy запись. Возвращает стартовый индекс                                       |
| **pseCommandBufferRawCommit(uint32_t startAbsoluteIndex, uint32_t count)**        | `void`                     | Публикует (передает игре) зарезервированные in-place команды                                                                |
| **pseCommandBufferRawWait(uint32_t absoluteIndex, uint32_t count)**               | `void`                     | Ожидает, пока игра отработает count-количество зарезервированных команд и вернет результаты                                 |
| **pseCommandBufferRawCommitAndWait(uint32_t startAbsoluteIndex, uint32_t count)** | `void`                     | Записывает RAW-команды и сразу переходит в режим ожидания ответов игры в этих слотах                                        |

## Event Buffer / Methods

| Сигнатура                                    | Тип возвращаемого значения | Описание                                                                                                                                   |
|----------------------------------------------|----------------------------|--------------------------------------------------------------------------------------------------------------------------------------------|
| **pseEventBufferTryGet(PseData\* pOutData)** | `int32_t`                  | Неблокирующая попытка забрать событие. Если событие есть, копирует его в **pOutData** и возвращает 1 (**true**), иначе 0 (**false**) |

## Архитектурные особенности

### Коды возврата `pseInitializeBuffers()`

| Значение | Статус              | Причина                                      | Действия системы                                                                                                                 |
|:--------:|---------------------|----------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------|
|  **0**   | **Успех**           | Подключение выполнено штатно                 | Память спроецирована, вызвана **C++** инициализация, **SDK** готов к работе                                                      |
|  **-1**  | **Ошибка открытия** | Не удалось открыть объект File Mapping       | `OpenFileMappingA` вернул `NULL`. Скорее всего, хост-процесс (игра) еще не запущен или не создал сегмент                         |
|  **-2**  | **Ошибка маппинга** | Не удалось спроецировать представление файла | `MapViewOfFile` вернул `NULL`. Выделенный `HANDLE` автоматически закрывается (`CloseHandle`), указатель сбрасывается в `nullptr` |
