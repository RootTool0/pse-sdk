## C-API Справочник функций

Экспортируемый C-интерфейс _(`extern "C"`)_ для интеграции **SDK** с **другими языками программирования** и обеспечения **бинарной совместимости** _(ABI)_

## Buffers / Core

| Сигнатура                        | Тип возвращаемого значения | Аргументы | Описание                                                       |
|----------------------------------|----------------------------|-----------|----------------------------------------------------------------|
| **pseInitializeBuffers()**       | `int32_t`                  | **-**     | Инициализирует и аллоцирует **Shared Memory**                  |
| **pseDeinitializeBuffers()**     | `void`                     | **-**     | Освобождает дескрипторы и закрывает сегмент разделяемой памяти |

| Сигнатура                        | Тип возвращаемого значения | Аргументы | Описание                                                                |
|----------------------------------|----------------------------|-----------|-------------------------------------------------------------------------|
| **pseGetBuffersAddress()**       | `PseBuffers*`              | **-**     | Возвращает указатель на корень структуры **PseBuffers**                 |
| **pseGetCommandBufferAddress()** | `PseCommandBuffer*`        | **-**     | Возвращает прямой указатель на **командный буфер**                      |
| **pseGetEventBufferAddress()**   | `PseEventBuffer*`          | **-**     | Возвращает прямой указатель на **событийный буфер**                     |
| **pseGetSharedMemoryHandle()**   | `void*`                    | **-**     | Возвращает системный дескриптор (**Handle**) созданного сегмента **ОС** |

## Command Buffer / Methods

### Базовые функции

| Сигнатура                         | Тип возвращаемого значения | Аргументы | Описание                                                                        |
|-----------------------------------|----------------------------|-----------|---------------------------------------------------------------------------------|
| **pseCommandBufferSynchronize()** | `void`                     | **-**     | Блокирует поток (**Spin-wait**), пока игра не выполнит все отправленные команды |

### Поштучный режим (SINGLE - Immediate Access)

Синхронный **RPC-механизм**: "запрос-ответ" через одну ячейку памяти

| Сигнатура                                                     | Тип возвращаемого значения | Аргументы                                                 | Описание                                                                                                    |
|---------------------------------------------------------------|----------------------------|-----------------------------------------------------------|-------------------------------------------------------------------------------------------------------------|
| **pseCommandBufferSinglePush(pBufferData)**                   | `uint32_t`                 | `const PseBufferData* pBufferData`                        | Запись одной команды. Возвращает абсолютный индекс слота                                                    |
| **pseCommandBufferSingleWait(absoluteIndex, pOutBufferData)** | `void`                     | `uint32_t absoluteIndex`, `PseBufferData* pOutBufferData` | Ожидает завершения на индексе и копирует результат в **pOutBufferData**                                     |
| **pseCommandBufferSinglePushAndWait(pBufferData)**            | `void`                     | `PseBufferData* pOutBufferData`                           | Синхронный вызов: отправляет команду и блокирует поток, а результат записывает обратно в **pOutBufferData** |

### Пакетный режим (BATCH - Copying)

Групповой конвейер команд: Результаты возвращаются в тот же самый исходный массив данных

| Сигнатура                                                        | Тип возвращаемого значения | Аргументы                                                                   | Описание                                                                                       |
|------------------------------------------------------------------|----------------------------|-----------------------------------------------------------------------------|------------------------------------------------------------------------------------------------|
| **pseCommandBufferBatchPush(pBufferData, count)**                | `uint32_t`                 | `const PseBufferData* pBufferData`, `uint32_t count`                        | Копирует пакет из **count**-количество команд в кольцо. Возвращает стартовый индекс            |
| **pseCommandBufferBatchWait(absoluteIndex, pBufferData, count)** | `void`                     | `uint32_t absoluteIndex`, `PseBufferData* pOutBufferData`, `uint32_t count` | Блокирует поток до выполнения пакета игрой и заменяет массив **pOutBufferData** результатами   |
| **pseCommandBufferBatchPushAndWait(pBufferData, count)**         | `void`                     | `PseBufferData* pOutBufferData`, `uint32_t count`                           | Синхронно отправляет пакет и ожидает перезаписи **pOutBufferData** выходными результатами игры |

### Режим прямого доступа (RAW - In-Place / Zero-Copy)

Максимально производительный режим: **SDK** пишет команду прямо в кэш-линию **Shared Memory**, а затем там же дожидается результата игры

| Сигнатура                                               | Тип возвращаемого значения | Аргументы                                       | Описание                                                                                                                    |
|---------------------------------------------------------|----------------------------|-------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------|
| **pseCommandBufferRawAt(absoluteIndex)**                | `PseBufferData*`           | `uint32_t absoluteIndex`                        | Возвращает прямой указатель на **PseBufferData** ячейку по абсолютному индексу в кольцевом буфере для **raw чтения/записи** |
| **pseCommandBufferRawReserve(count)**                   | `uint32_t`                 | `uint32_t count`                                | Резервирует count-количество слотов под Zero-Copy запись. Возвращает стартовый индекс                                       |
| **pseCommandBufferRawCommit(startIndex, count)**        | `void`                     | `uint32_t startAbsoluteIndex`, `uint32_t count` | Публикует (передает игре) зарезервированные in-place команды                                                                |
| **pseCommandBufferRawWait(absoluteIndex, count)**       | `void`                     | `uint32_t absoluteIndex`, `uint32_t count`      | Ожидает, пока игра отработает count-количество зарезервированных команд и вернет результаты                                 |
| **pseCommandBufferRawCommitAndWait(startIndex, count)** | `void`                     | `uint32_t startAbsoluteIndex`, `uint32_t count` | Записывает RAW-команды и сразу переходит в режим ожидания ответов игры в этих слотах                                        |

## Event Buffer / Methods

| Сигнатура                                | Тип возвращаемого значения | Аргументы                       | Описание                                                                                                                                   |
|------------------------------------------|----------------------------|---------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------|
| **pseEventBufferTryGet(pOutBufferData)** | `int32_t`                  | `PseBufferData* pOutBufferData` | Неблокирующая попытка забрать событие. Если событие есть, копирует его в **pOutBufferData** и возвращает 1 (**true**), иначе 0 (**false**) |

## Архитектурные особенности

### Коды возврата `pseInitializeBuffers()`

| Значение | Статус              | Причина                                      | Действия системы                                                                                                                 |
|:--------:|---------------------|----------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------|
|  **0**   | **Успех**           | Подключение выполнено штатно                 | Память спроецирована, вызвана **C++** инициализация, **SDK** готов к работе                                                      |
|  **-1**  | **Ошибка открытия** | Не удалось открыть объект File Mapping       | `OpenFileMappingA` вернул `NULL`. Скорее всего, хост-процесс (игра) ещё не запущен или не создал сегмент                         |
|  **-2**  | **Ошибка маппинга** | Не удалось спроецировать представление файла | `MapViewOfFile` вернул `NULL`. Выделенный `HANDLE` автоматически закрывается (`CloseHandle`), указатель сбрасывается в `nullptr` |
