## Архитектурные особенности

### Оптимизация булевых параметров (`int8_t` вместо `bool`)
В целях обеспечения строгой бинарной совместимости (**ABI compliance**) между различными компиляторами, языками (**C++, C#, Rust, Python**) и средами исполнения, все логические параметры (**флаги включения/выключения**) передаются через тип `int8_t` вместо стандартного `bool`:
- **Проблема встроенного `bool`:** В стандарте **C++** размер типа `bool` не зафиксирован жестко и может отличаться в зависимости от платформы и настроек компилятора, что недопустимо при прямой разметке **Shared Memory** по фиксированным смещениям
- **Соглашение о валидации:** Любое значение `Value != 0` интерпретируется обработчиком игры как **`true`**, а `Value == 0` наоборот строго эквивалентно **`false`**

### Поведение регистров при смене класса (Команда `PSE_COMMAND_ELEMENT_SET_CLASS`)
Команда изменения класса элемента (`PSE_COMMAND_ELEMENT_SET_CLASS`) **полностью** пересоздает элемент на в том же GUID, сохраняя **только** GUID, Трансформацию, Указатель-значение callback и Видимость:
- **Полный сброс данных:** Старые значения всех регистров полностью стираются и сбрасываются в дефолтное значение для данного элемента. Новый элемент начинает работу с чистыми регистрами по умолчанию
- **Разная интерпретация:** Копирование данных между классами лишено смысла, так как каждый элемент интерпретирует одни и те же регистры по разному. Именно поэтому их значения сбрасываются, да-бы для исключенить логические ошибки 
- **Сохранение данных через SDK:** Если данные старого элемента нужно перенести на новый, вы должены сделать это самостоятельно в коде своей программы: получить текущее значение всех регистров через `PSE_COMMAND_ELEMENT_GET_ALL_REGISTERS` и State через `PSE_COMMAND_ELEMENT_GET_STATE` (или общей командой `PSE_COMMAND_ELEMENT_GET_STATE_AND_ALL_REGISTERS`), сменить класс элемента (`PSE_COMMAND_ELEMENT_SET_CLASS`) и записать значения регистров обратно через `PSE_COMMAND_ELEMENT_SET_ALL_REGISTERS` и State через `PSE_COMMAND_ELEMENT_SET_STATE` (или общей командой `PSE_COMMAND_ELEMENT_SET_STATE_AND_ALL_REGISTERS`)
- **Но будьте осторожны:** Не забывайте сверяться с таблицей назначения регистров для элементов и проверять, какие именно данные вы переносите, так как для двух разных элементов один и тот же регистр может кардинально отличаться по смыслу и логике работы
