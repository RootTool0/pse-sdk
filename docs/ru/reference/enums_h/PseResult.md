## [Portal Solver Editor SDK](../../pse_sdk.md) > [Reference](../index.md) > [Enums.h](index.md) > [PseResult]()

<br>

| Значение (HEX) | Название                                  | Описание                                                                           |
|:--------------:|-------------------------------------------|------------------------------------------------------------------------------------|
| **0x00000000** | PSE_RESULT_SUCCESS                        | Команда успешно выполнена игрой                                                    |
| **0x00000001** | PSE_RESULT_ERROR_COMMAND_NOT_FOUND        | Переданный код команды не распознан игрой                                          |
| **0x00000002** | PSE_RESULT_ERROR_COMMAND_NOT_IMPLEMENTED  | Команда найдена, но логика ее выполнения ещё не реализована в игре                 |
| **0x00000003** | PSE_RESULT_ERROR_EXECUTION_FAILED         | Неизвестная критическая ошибка во время выполнения команды в игре                  |
| **0x00000004** | PSE_RESULT_ERROR_ARRAY_INDEX_OUT_OF_RANGE | Выход за пределы массива при обработке команды                                     |
| **0x00000005** | PSE_RESULT_ERROR_GUID_NOT_FOUND           | Указанный GUID (**PseGUID**) объекта не найден в текущем мире игры                 |
| **0x00000006** | PSE_RESULT_ERROR_INVALID_OBJECT_TYPE      | Ошибка приведения типов (**Cast failed**). Объект с данным GUID имеет другой класс |
| **0xFFFFFFFF** | PSE_RESULT_NONE                           | Служебное пустое состояние                                                         |

## Архитектурные особенности

- Код ошибки `ARRAY_INDEX_OUT_OF_RANGE` является **универсальным** для любых запросов к внутренним ресурсам игры. Если передан невалидный индекс или игра не может найти **класс**, **материал** или **меш**, то **игра вернет** именно **этот код ошибки**, так как на низком уровне это всегда приводит к неудачной попытке доступа по индексу во внутренние статические массивы **игрового движка**
