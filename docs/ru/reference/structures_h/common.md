## [Portal Solver Editor SDK](../../pse_sdk.md) > [Reference](../index.md) > [Structures.h](index.md) > [Common]()

<br>

Краткий справочник базовых типов данных и структур, используемых в **SDK**

## Алиасы

| Имя алиаса      | Тип        | Размер<br>(в байтах) | Описание                                                                                                                                                                                              |
|-----------------|------------|:--------------------:|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **PseGUID**     | `uint64_t` |          8           | Глобальный уникальный идентификатор                                                                                                                                                                   |
| **PseRegister** | `uint32_t` |          4           | Регистр внутри элементов _(Для удобной есть хелпер-функции в `pse::Register::`, см. **[[Reference > Pse.hpp > Register]](../pse_hpp/Register.md)**)_                                                  |
| **PseState**    | `int8_t`   |          1           | Сквозная переменная состояния. Связывает элементы друг с другом _(главная нить судьбы)_                                                                                                               |
| **PseCallback** | `uint64_t` |          8           | Анонимный маркер пользовательского контекста _(хранит адрес функции в памяти элементов в игре)_. Игра сохраняет его и возвращает обратно при наступлении события с элементом без каких-либо изменений |

## Структуры

| Имя структуры    | Поля                                                      | Размер<br>_(в байтах)_ | Описание                    |
|------------------|-----------------------------------------------------------|:----------------------:|-----------------------------|
| **PseVector2**   | `float x`, `float y`                                      |           8            | Двухмерный вектор           |
| **PseVector3**   | `float x`, `float y`, `float z`                           |           12           | Трехмерный вектор           |
| **PseQuat**      | `float x`, `float y`, `float z`, `float w`                |           16           | Кватернион                  |
| **PseTransform** | `PseQuat quat`, `PseVector3 location`, `PseVector3 scale` |           40           | Трансформ объекта           |
| **PseColor**     | `uint8_t r`, `uint8_t g`, `uint8_t b`,                    |           4            | Цвет в формате RGBA (0-255) |
