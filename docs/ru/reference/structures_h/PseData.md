## [Portal Solver Editor SDK](../../pse_sdk.md) > [Reference](../index.md) > [Structures.h](index.md) > [PseData]()

<br>

Универсальная **64-байтовая структура** для **Shared Memory**

Безымянна, не имеет своей логики и выступает в роли транспортера _("рабочей лошадки")_ данных между **игрой** и **SDK**

Размер атомарен и оптимизирован под размер **кэш линии _(64 байта)_** для **кольцевого буфера**

## Поля

| Поле                 |  Смещение<br>_(в байтах)_  |  Размер<br>_(в байтах)_  | Описание                                                                                |
|----------------------|:--------------------------:|:------------------------:|-----------------------------------------------------------------------------------------|
| **uint32_t header**  |            `0`             |           `4`            | Заголовок пакета. Определяет тип сообщения и контекст для интерпретации данных в `data` |
| **uint8_t[60] data** |            `4`             |           `60`           | Сырой массив для полезной нагрузки _(payload)_, куда упаковываются параметры            |
