## Anti Expropriation Field [+]

![](../../assets/portal_solver_logo.png)

**PseClass:** `0x0004`

**Описание Элемента:** Поле анти-экспроприации, способное уничтожать вещи, убивать игрока, или переключать состяния **Солвер Гана**

**Set State:** Не используется _(нет логики)_

**Get State:** Включает поле при **State != 0**

**Разметка регистров:**

| Индекс | Наименование        | Формат данных                      | Описание                                                                                                   |
|:------:|---------------------|------------------------------------|------------------------------------------------------------------------------------------------------------|
| `[0]`  | **Flags**           | `____________________________SSPO` | `SS` - Режим действия с **Солвер Ганом**<br>`P` - Бит, убивающий игрока<br>`O` - Бит, уничтожающий обьекты |
| `[1]`  | **Color**           | `________RRRRRRRRGGGGGGGGBBBBBBBB` | `R...G...B` - Цвет поля                                                                                    |
| `[2]`  | **Size**            | `XXXXXXXXXXXXXXXXYYYYYYYYYYYYYYYY` | `X...X` - Длина поля<br>`Y...Y` - Высота поля                                                              |
| `[3]`  | **НЕ ИСПОЛЬЗУЕТСЯ** | `________________________________` | **-**                                                                                                      |
| `[4]`  | **НЕ ИСПОЛЬЗУЕТСЯ** | `________________________________` | **-**                                                                                                      |
| `[5]`  | **НЕ ИСПОЛЬЗУЕТСЯ** | `________________________________` | **-**                                                                                                      |
| `[6]`  | **НЕ ИСПОЛЬЗУЕТСЯ** | `________________________________` | **-**                                                                                                      |
| `[7]`  | **НЕ ИСПОЛЬЗУЕТСЯ** | `________________________________` | **-**                                                                                                      |

**Дополнительная информация**:

- В регистре `[0]` биты `SS` являются перечислением типа `uint2_t`, содержащей в себе:
  - **None** _(= 0)_ - Ничего не делает с **Солвер Ганом**
  - **Switch** _(= 1)_ - Переключает состояние **Солвер Гана**
  - **Enable** _(= 2)_ - Активирует **Солвер Ган**
  - **Disable** _(= 3)_ - Деактивирует **Солвер Ган**
  - _Любые другие невалидные значения будут относиться к **None**_

- В регистре `[2]` биты `X...X` и `Y...Y` имеют тип `uint16_t`, то есть **знаковое 16-битное целое число**

## Pedestal Button [+]

![](../../assets/portal_solver_logo.png)

**PseClass:** `0x0005`

**Описание Элемента:** Пьедестал-кнопка, активируемая исключительно рукой игрока _(не Солвер Ганом)_

**Set State:** Не используется _(нет логики)_

**Get State:** Возвращает `1` при активации, и `0` при деактивации, но режиме таймера (**Timer**) при активации возвращает кол-во секунд

**Разметка регистров:**

| Индекс | Наименование          | Формат данных                      | Описание                                                           |
|:------:|-----------------------|------------------------------------|--------------------------------------------------------------------|
| `[0]`  | **Flags + Timer**     | `_______________________SSSSSSSTT` | `S...S` - Количество секунд таймера<br>`TT` - Тип пьедестал-кнопки |
| `[1]`  | **Color Activated**   | `________RRRRRRRRGGGGGGGGBBBBBBBB` | `R...G...B` - Цвет пьедестал-кнопки в активированном состоянии     |
| `[2]`  | **Color Deactivated** | `________RRRRRRRRGGGGGGGGBBBBBBBB` | `R...G...B` - Цвет пьедестал-кнопки в деактивированном состоянии   |
| `[3]`  | **НЕ ИСПОЛЬЗУЕТСЯ**   | `________________________________` | **-**                                                              |
| `[4]`  | **НЕ ИСПОЛЬЗУЕТСЯ**   | `________________________________` | **-**                                                              |
| `[5]`  | **НЕ ИСПОЛЬЗУЕТСЯ**   | `________________________________` | **-**                                                              |
| `[6]`  | **НЕ ИСПОЛЬЗУЕТСЯ**   | `________________________________` | **-**                                                              |
| `[7]`  | **НЕ ИСПОЛЬЗУЕТСЯ**   | `________________________________` | **-**                                                              |

**Дополнительная информация**:

- В регистре `[0]` биты `TT` являются перечислением типа `uint2_t`, содержащей в себе:
  - **Switch** _(= 0)_ - Переключатель, который меняет состояние (вкл/выкл) при каждом клике
  - **Click** _(= 1)_ - Клик, который активируется на небольшое время
  - **Timer** _(= 2)_ - Таймер, который активируется на заданное коичество секунд (регистр `[0]` биты `S...S`)
  - **Once** _(= 3)_ - Одноразово активируется один раз, блокируется, и больше не выключается
  - _Любые другие невалидные значения будут относиться к **Switch**_

- В регистре `[0]` биты `S...S` является 7-битным беззнаковым числом `uint7_t` - и нет это не ошибка

| `[3]`  | **Flag + Laser Color** | `_______VRRRRRRRRGGGGGGGGBBBBBBBB` | `V` - Бит, который активаирует приемник **только** от указанного приходящего цвета лазера |

**Дополнительная информация**:

- В регистре `[0]` биты `TTTT` являются перечисление _(с функцией битовых флагов)_ с типом `uint4_t`, содержащей в себе:
  - **None** _(= 0b0000)_ - Цель: Триггер ни на что не реагирует
  - **Player** _(= 0b0001)_ - Цель: Триггер реагирует на игрока
  - **Cubes** _(= 0b0010)_ - Цель: Триггер реагирует на кубики
  - _(биты можно совмещать операцией, например: 0b0011 - Триггер среагирует на игрока или на кубики)_
- В регистре `[0]` биты `CCCC` являются перечисление _(с функцией битовых флагов)_ с типом `uint4_t`, содержащей в себе:
  - **None** _(= 0b0000)_ - Условие: Триггер никак сработает _(вернет `0`)_
  - **On Overlap In** _(= 0b0001)_ - Условие: Триггер сработает при входе _(и вернет `1`)_
  - **On Overlap Out** _(= 0b0010)_ - Условие: Триггер сработает при выходе _(и вернет `1`)_
  - _(биты можно совмещать, например: 0b0011 - Триггер среагирует при входе или выходе из него, и в обоих случаях вернет `1`)_
- В регистре `[0]` биты `AAAA` являются перечисление _(с функцией битовых флагов)_ с типом `uint4_t`, содержащей в себе:
  - **None** _(= 0b0000)_ - Действие: Триггер ничего не сделает
  - **Call** _(= 0b0001)_ - Действие: Триггер вызовет событие **State**
  - **Destroy** _(= 0b0010)_ - Действие: Триггер уничтожит обьект _(уничтожит кубик или убьет игрока)_
  - _(биты можно совмещать, например: 0b0011 - Триггер вызовет событие + уничтожит обьект)_
- Комментарии к логике работы **Триггера**:
  - Зависимость **Действия** от **Условия**: **Действия** _(например Destroy)_ выполняются только при совпадении текущего события _(Вход в/Выход из триггера)_ с заданным **Условием** _(On Overlap In/On Overlap Out)_. Исключением является **Действие Call** 
  - **Исключение** для **Действия Call**: Если включено **действие Call**, то триггер будет создавать события _(OnElementChanged)_, игнорируя любые проверки **Условий**
  - **Но**: Даже если **действие Call** будет выключено, и события _(OnElementChanged)_ не будут создаваться, то все равно переменная **State** внутри триггера будет молча обновляться и всегда будет доступна, то есть ее всегда можно будет прочитать
