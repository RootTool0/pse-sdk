## Pedestal Button [x]

![](../../Assets/PortalSolverLogo.png)

**PseClass:** `0x0005`

**Описание Элемента:** Пьедестал-кнопка, активируемая исключительно рукой игрока _(не Солвер Ганом)_

**Set State:** Не используется _(нет логики)_

**Get State:** Возвращает `1` при активации, и `0` при деактивации, но режиме таймера (**Timer**) при активации возвращает кол-во секунд

**Разметка регистров:**

| Индекс | Наименование          | Формат данных                      | Описание                                                               |
|:------:|-----------------------|------------------------------------|------------------------------------------------------------------------|
| `[0]`  | **Flags + Timer**     | `_________________SSSSSSSTTTTTTTT` | `S...S` - Количество секунд таймера<br>`T...T` - Тип пьедестал-кнопки  |
| `[1]`  | **Color Activated**   | `________RRRRRRRRGGGGGGGGBBBBBBBB` | Цвет пьедестал-кнопки в активированном состоянии                       |
| `[2]`  | **Color Deactivated** | `________RRRRRRRRGGGGGGGGBBBBBBBB` | Цвет пьедестал-кнопки в деактивированном состоянии                     |
| `[3]`  | **НЕ ИСПОЛЬЗУЕТСЯ**   | `________________________________` | **-**                                                                  |
| `[4]`  | **НЕ ИСПОЛЬЗУЕТСЯ**   | `________________________________` | **-**                                                                  |
| `[5]`  | **НЕ ИСПОЛЬЗУЕТСЯ**   | `________________________________` | **-**                                                                  |
| `[6]`  | **НЕ ИСПОЛЬЗУЕТСЯ**   | `________________________________` | **-**                                                                  |
| `[7]`  | **НЕ ИСПОЛЬЗУЕТСЯ**   | `________________________________` | **-**                                                                  |

**Дополнительная информация**:

- Регистре `[0]` биты `T...T` являются перечислением типа `uint8_t`, содержащей в себе:
  - **Switch** _(= 0)_ - Переключатель, который меняет состояние (вкл/выкл) при каждом клике
  - **Click** _(= 1)_ - Клик, который активируется на небольшое время
  - **Timer** _(= 2)_ - Таймер, который активируется на заданное коичество секунд (регистр `[0]` биты `S...S`)
  - **Once** _(= 3)_ - Одноразово активируется один раз, блокируется, и больше не выключается
  - _Любые другие невалидные значения будут относиться к **Switch**_

- Регистре `[0]` биты `S...S` является 7-битным беззнаковым числом `uint7_t` - и нет это не ошибка
