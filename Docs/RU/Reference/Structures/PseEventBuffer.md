## [Portal Solver Editor SDK](../../PortalSolverEditorSDK.md) > [Reference](../Index.md) > [Structures](Index.md) > [PseEventBuffer]()

<br>

Реализация кольцевого буфера событий (**Lock-free Ring Buffer**) для асинхронного межпроцессного взаимодействия (**Shared Memory**)

Обеспечивает потокобезопасную передачу данных между **игрой** (продюсер) и **SDK** (консумер) без использования тяжелых системных примитивов синхронизации

Выравнивание по границам **кэш-линий** гарантирует максимальную пропускную способность шины памяти

## Поля

| Поле                                | Смещение<br>_(в байтах)_ | Размер<br>_(в байтах)_  | Описание                                                                                                                      |
|-------------------------------------|:------------------------:|:-----------------------:|-------------------------------------------------------------------------------------------------------------------------------|
| **PseBufferData buffer[256]**       |           `0`            | **16 384**<br>_(16 КБ)_ | Кольцевой массив атомарных 64-байтовых ячеек данных. Выровнен по кэш-линии (`alignas(64)`)                                    |
| **std::atomic<uint32_t> gameIndex** |         `16 384`         |          **4**          | Атомарный индекс записи **игры** _(Producer Index)_. Выровнен независимо (`alignas(64)`) для предотвращения **False Sharing** |
| **static inline uint32_t pseIndex** |    **Вне структуры**     |          **4**          | Глобальный индекс чтения **SDK** _(Consumer Index)_. Существует в памяти самого **SDK** и не размещается в **Shared Memory**  |

## Методы и Операторы _(только для C++)_

| Сигнатура                             | Тип возвращаемого значения | Аргументы                         | Описание                                                                                                                                            |
|---------------------------------------|----------------------------|-----------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|
| **operator[]\(absoluteIndex\)**       | `PseBufferData&`           | `uint32_t absoluteIndex`          | Перегруженный оператор доступа. Преобразует абсолютный индекс в циклический через маску: `absoluteIndex & (PSE_EVENT_BUFFER_SIZE - 1)`              |
| **operator[]\(absoluteIndex\) const** | `const PseBufferData&`     | `uint32_t absoluteIndex`          | Константная версия оператора доступа для безопасного чтения без модификации буфера                                                                  |
| **tryGet(outPseBufferData)**          | `bool`                     | `PseBufferData& outPseBufferData` | Неблокирующая попытка вычитать событие. Проверяет разницу индексов с барьером памяти `acquire`. Возвращает `true`, если событие успешно скопировано |

## Архитектурные особенности

**Потоковая модель (Single-Producer / Single-Consumer):** Метод `tryGet` использует упорядочивание памяти `std::memory_order_acquire`. Оно гарантирует, что все данные, записанные **игрой** до обновления `gameIndex`, гарантированно валидны на стороне **SDK** в момент чтения
